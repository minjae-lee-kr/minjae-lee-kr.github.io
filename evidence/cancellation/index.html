상품 조회가 타임아웃돼 다시 요청했습니다. 첫 요청의 재고 작업이 아직 실행 중이라면, 재시도로 작업이 더 늘어날 수 있습니다.

Apollo Federation은 여러 GraphQL 서버를 하나의 API로 연결합니다. 이 개인 실험은 실제 HTTP 호출에 가상 재고 작업을 연결합니다. 실행 슬롯(permit)은 동시에 허용하는 작업의 자리입니다. 아래에서 슬롯 수와 실제 작업 수가 언제 달라지는지 비교해 보세요.
